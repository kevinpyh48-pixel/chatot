# 교수 대본 정리 프롬프트

chatot의 ⑤단계 지침이다. 녹취록은 곧 이 대본이며, 이미 만든 녹취록을 "대본으로 다시 만들어줘"라고 할 때도 같다. 요약본이 아니다. 교수가 한 말이 하나도 빠지지 않는 **대본**이 목적이다.

## 입력

- raw 전사 또는 기존 녹취록 `.md`(한글 음차 영어, 오타가 섞인 상태)
- 강의록 PDF 또는 변환본. 슬라이드 텍스트와 사용자 손필기가 들어 있다. 손필기는 수업 중 교수가 한 말을 사용자가 적어둔 것이니 대본의 근거로 쓴다.

## 해야 할 일

1. **영단어 복원.** 한글로 적힌 영어 용어·약어·약품명·검사명을 전부 영어 원문으로 바꾼다(예: 다소프레이싱 → vasopressin). 슬라이드 순서와 발화 순서가 대체로 일치하니, 지금 어느 슬라이드를 설명 중인지 짚으면 후보가 좁혀진다.
2. **오타·끊김 다듬기.** 잘게 쪼개진 문장을 이어 줄글로 만든다. 확신이 없으면 원문을 두고 `(?)`를 붙인다. 창작 금지.
3. **손필기·슬라이드 텍스트 교차 참조.** 필기에만 남은 발언은 대본에 넣고, 녹취와 필기가 충돌하면 둘 다 적고 표시한다.
4. **누락 금지.** 핵심만 추리지 않는다. 교수의 말은 구어체 그대로(말버릇·농담·경험담 포함) 줄글로 옮긴다. 군더더기 감탄사 정도만 덜어낸다.
5. **별(⭐) 표시.** 교수가 여러 번 강조했거나 시험에 나온다고 언급한 대목은 ⭐를 붙이고 이유를 괄호로 적는다(예: ⭐ "시험에 나온다" 2회 언급).

## 구성

슬라이드를 **2~10장 단위, 주제별로 최대한 잘게** 나눈다. 구간마다:

```markdown
## 구간 제목 (p4~7)

교수가 한 말을 줄글로. ⭐ 표시는 해당 문장 앞에.
```

- 제목 끝에 쪽 범위를 `(p4~7)` 꼴로 단다(`p.`·`슬라이드`를 쓰지 않는다). 정리본 절 정렬이 이 쪽 번호로 돌아간다.
- 문장·문단 앞에 `[mm:ss]` 시각을 달지 않는다. 제목 뒤 백틱 시각도 달지 않는다. 시각은 교정 로그·불확실 항목에만 둔다(원음 대조용).
- `볼 슬라이드`·`핵심 내용`을 만들지 않는다. 쪽 번호는 제목에 있고 요약은 정리본이 맡는다.
- 교시가 바뀌는 지점에는 `**━━ N교시 ━━**` 한 줄만 둔다.
- 슬라이드와 발화가 어긋나는 곳은 문단 안에 ⚠️와 괄호 한 줄로 적는다(요약 항목에 넣지 않는다).

문서 맨 앞에 `## 목차`(구간 제목을 `[[#제목|제목]]` 링크로, 쪽 순서)를 둔다. 정리본이 생긴 뒤 `python3 -I ~/.claude/skills/chatot/scripts/format_transcript.py <강의 폴더 또는 과목 폴더> --apply`를 한 번 돌려 목차를 정리본 절(§) 체계로 묶는다. 정리본보다 먼저 돌리면 평면 목차로 굳으니 순서를 지킨다. 이 스크립트는 옛 형식(시각·볼 슬라이드·핵심 내용)도 한꺼번에 걷어내고, 원본은 `<일차>/_구버전/<YYMMDD>/`에 보관한다. 맨 끝에는 `## 교정 로그`(원문 → 복원·교정, 불확실 항목 `(?)`)를 남긴다.

## 출력

대화창에 코드로 보여주지 말고 **`.md` 파일로 저장**한다. 위치는 녹음과 같은 강의 폴더, 파일명 `<강의>_녹취록.md`(분할 녹음은 `_녹취록_1교시.md`). 소스 탐지가 `녹취록` 이름으로 찾으므로 `_교수대본`으로 바꾸지 않는다. 맨 끝에 `## 불확실·확인 요망`도 둔다. 사용자가 링크로 언제든 열어 볼 수 있어야 하니 경로를 링크로 알려준다.
