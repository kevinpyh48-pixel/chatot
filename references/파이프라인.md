# chatot 파이프라인 — 환경 제약과 트러블슈팅

## 이 맥에서 표준 방법이 막히는 이유

- **ffmpeg 없음** → whisper 계열에 *파일 경로*를 주면 내부에서 ffmpeg를 부르다 죽는다. 그래서 오디오를 numpy 배열로 읽어 **배열로 직접** 넘긴다.
- **brew 없음** → ffmpeg 설치도 불가.
- **시스템 파이썬(`/usr/bin/python3`)은 site-packages 쓰기 권한 없음** → `uv pip install --system` 실패. 격리 venv(`~/.cache/chatot/.venv`)를 쓴다.
- 단, `pymupdf`는 시스템 파이썬에 이미 있다 — PDF 텍스트 추출엔 추가 설치가 필요 없다.

## 증상별 대응

| 증상 | 원인 | 대응 |
|---|---|---|
| `FileNotFoundError: ffmpeg` | 경로를 그대로 넘김 | 스크립트를 쓰지 않고 직접 호출한 경우다. `transcribe.py`를 써라(afconvert + soundfile 경유). |
| `ModuleNotFoundError: mlx_whisper` | venv 아닌 파이썬으로 실행 | `~/.cache/chatot/.venv/bin/python`으로 실행. |
| 같은 문장이 수백 줄 반복 | 무음 구간 whisper 환각 | 스크립트가 `condition_on_previous_text=False`로 억제하지만 완전하진 않다. SKILL.md ④ 환각 컷을 반드시 수행. |
| 영어 문장으로 나옴 | 언어 자동감지 실패 | 스크립트가 `language="ko"` 고정이니 발생하면 오디오 자체를 확인. |
| 첫 실행이 오래 걸림 | HF 모델(~1.6GB) 다운로드 | 정상. 이후 캐시된다. |

## grounding의 실제 효과 — 실측(2026-07-29, 뇌하수체 후엽 강의 150초 A/B)

같은 150초를 세 조건으로 돌려 비교했다.

| 조건 | 결과 |
|---|---|
| 프롬프트 없음 | `post-future`, `anti-dietic hormone`, `arginine vasopressin`(이건 맞음) |
| 영어 용어 80개 나열 | `포스트피추추적인`, `얼린이 마스쿠라이로 신` — **오히려 악화** |
| 한국어 문장 + 영문 용어(문체 샘플) | `vascular supply`, `Oxytocin`, `Iscemic Damage` — **약간 개선** |

**결론**: whisper의 initial_prompt는 어휘 사전이 아니라 **문체 유도**로 동작한다. 용어 나열은 "영어로 받아쓰라"는 신호가 되어 한국어 발화와 충돌한다. 그래서 SKILL.md ②는 문단형 프롬프트를 쓴다.

그리고 셋 다 크게 깨진다 — 병목은 프롬프트가 아니라 **한국어 억양으로 발음된 영어 용어**라는 오디오 자체의 성질이다. 비-turbo `whisper-large-v3-mlx`도 시도했으나 150초를 10분 안에 못 끝내 실용성이 없었다. **정확도는 사후 교정(SKILL.md ⑤)에서 만들어진다** — grounding은 보너스로만 취급하라.

## 스모크 테스트

새 맥이나 환경 변경 후 파이프라인이 살아있는지 1분 안에 확인:
```bash
~/.cache/chatot/.venv/bin/python ~/.claude/skills/chatot/scripts/transcribe.py "아무_강의.m4a" --out /tmp/smoke.md --limit-seconds 60
```
타임스탬프가 붙은 한국어 줄이 나오면 정상.
